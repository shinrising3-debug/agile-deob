Drop Agile.NET-protected test binaries here (they're git-ignored).

Good sources for **legal** practice targets:

- Protect a throwaway "hello world" assembly with an Agile.NET trial yourself,
  then try to recover it.
- CTF reversing challenges that ship Agile.NET/CliSecure binaries.
- The de4dot test corpus and public malware-analysis write-ups.

Don't commit binaries you don't have the rights to redistribute.
